# TaskFlow SaaS Landing Page

TaskFlow is a modern and responsive SaaS landing page built for startups and software products. It includes a clean hero section, feature cards, pricing plans, testimonials, FAQ, contact form, and modern UI animations.

## Features

- Responsive SaaS landing page
- Clear hero section with CTA buttons
- HTML/CSS dashboard mockup
- 6 feature cards
- Free, Pro, and Business pricing plans
- Realistic testimonials
- FAQ accordion
- Contact form UI with validation
- Dark/light mode design
- Smooth scroll and hover effects
- Portfolio demo safeguards for CTA and contact actions

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js backend
- Local JSON file storage

## Backend Routes

- `GET /api/health`
- `GET /api/features`
- `GET /api/pricing`
- `GET /api/faqs`
- `GET /api/leads`
- `GET /api/trials`
- `POST /api/leads`
- `POST /api/trials`

## Run Backend

```bash
npm start
```

The backend runs on port `4100` by default. Lead captures and trial requests are saved in local JSON files inside the `data` folder.

## Purpose

This project is designed for startup founders, SaaS companies, AI tool builders, and indie hackers who need a professional landing page before launching their product.

## Portfolio Case Study

### Project Overview

TaskFlow is a modern SaaS landing page built for startup founders and software companies that want to promote their product before launch. The website includes a conversion-focused hero section, feature cards, pricing plans, testimonials, FAQ, contact form, and modern responsive design.

### Problem

Many startups need a professional landing page before launching their product. They need a website that clearly explains the product, builds trust, and encourages users to sign up, book a demo, or contact the team.

### Solution

I designed and built a responsive SaaS landing page that presents the product clearly and professionally. The layout focuses on conversion, readability, pricing clarity, and startup-style branding.

### Result

The final landing page gives startups a professional online presence that can be used to attract early users, collect leads, explain pricing, and promote a SaaS product before launch.
